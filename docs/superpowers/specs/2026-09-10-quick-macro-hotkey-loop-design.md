# 设计：uiu 极速按键精灵模式（F10 录制 / F12 回放与重复行为检测）

日期：2026-09-10 · 状态：已确认（采用经典按键精灵热键 F10/F12/F11）

## 1. 背景与目标

当前 uiu 已具备基于 Windows 低级钩子的宏录制（`macro_record`）与回放（`macro_play`），但交互形式偏“命令行/工具调用”，用户必须先为宏命名、在终端或对话中触发，录完再切回来看结果，割裂感较强。

用户在日常重复性操作（网页数据录入、游戏刷任务、表格批量处理、特定客户端连点）中最核心的诉求是：
> **经典按键精灵体验**：
> 鼠标移到目标窗口起点，按下 `F10` 开始录制，人手动操作一遍，再次按 `F10` 封包结束循环；
> 随后按下 `F12`，立刻毫秒级重复刚才两次 `F10` 中间的动作序列。
> 连击或 `Ctrl+F12` 可多轮循环，`F11` 随时紧急刹车。同时具备智能识别多轮操作中重复循环体的能力。

## 2. 核心原则（用户约束）

- **极致精简，零新依赖**：复用现有的 `macro_recorder.py` 低级钩子与 `macro_player.py` / `gui_primitives.py` 原语，不引入任何额外第三方三方库（如 pynput）。
- **零打扰物理盲操**：录制和回放期间全程无需切回终端或对话框，使用 Windows 原生 `MessageBeep` / `Beep` 提供声音反馈。
- **物理安全熔断**：任何时刻按 `F11` 或将鼠标甩到屏幕左上角（FAILSAFE）瞬间强行掐断执行。
- **对话与热键一体**：既可以在对话中由用户说「我要做重复动作，帮我记一下」开启，也可以由 CLI / TUI 独立启动快捷守护。

## 3. 详细交互设计

### 3.1 热键流：F10 录制 / F12 重复回放 / F11 紧急刹车

```
[用户在任意软件中就绪]
       │
       ├─► 按下 F10 ──► 响 1 声高频蜂鸣 (1000Hz, 150ms) ──► 启动事件捕获 (RECORDING)
       │   （正常操作：点击、控制键、滚动、等待）
       │
       ├─► 再次按下 F10 ──► 响 2 声清脆双音 (1500Hz, 100ms * 2) ──► 封包生成 _quick_loop.json (READY)
       │
       ├─► 按下 F12 ──► 响 1 声低沉确认音 (800Hz, 80ms) ──► 毫秒级重放 1 次刚才的循环
       │
       ├─► 按下 Ctrl+F12 ──► 循环执行（默认 10 次，或按 F11 刹车）
       │
       └─► 任何时候按下 F11 ──► 响 1 声长低音 (400Hz, 300ms) ──► 瞬间强制掐断录制或回放
```

* **循环次数控制**：
  * **单次单按**：按一次 `F12`，执行 1 次。
  * **快速连按或组合键**：
    * `Ctrl + F12`：连续循环执行（默认 10 次，执行期间随时按 `F11` 刹车）。
    * 对话控制：在 uiu 中直接说「把刚才录的跑 50 遍」或「无限循环直到我按 F11」。
* **中止键**：
  * `F11`：无论是在录制还是在回放，按下立即停止并退出循环。

### 3.2 声音反馈（零 UI 盲操保障）

在 Windows 下使用 `ctypes.windll.kernel32.Beep(freq, duration)` 或 `winsound.MessageBeep()`：
1. **开始录制（F10）**：`Beep(1000, 150)`（滴~）
2. **结束录制（F10）**：`Beep(1400, 100)` + `Beep(1800, 150)`（滴滴~）
3. **开始回放（F12）**：`Beep(800, 80)`（嘟~）
4. **回放完毕**：`Beep(1200, 100)`（哔~）
5. **紧急中止（F11）**：`Beep(400, 300)`（沉闷长音）

### 3.3 重复行为自动检测（智能切片）

当用户告诉 uiu：“我后面动作有重复，帮我找到重复行为并记录”时：
1. 用户不需要掐准点按 F10，而是自然地把该套操作连续做 2~3 遍；
2. 录制器记录整段动作流（事件序列 $E_1, E_2, \dots, E_n$）；
3. **轻量序列模式匹配算法**：
   * 将动作流简化为特征串（如 `Click(x,y)`、`Key(tab)`、`Scroll`）；
   * 通过滑动窗口与自相关匹配，找出最大重复子序列（周期 $T$）；
   * 自动剥离首次操作的前置准备动作（如切窗口、找光标）与结束动作，精准切片出「核心单次循环步骤」；
   * 自动存为宏并通知用户：“已自动识别出循环周期（共 N 步，重复了 M 次），按 F12 即可连续回放”。

## 4. 模块划分与代码实现规划

1. **`src/uiu/quick_macro.py`（~150 行）**：
   * 封装后台快捷键监听器（`QuickMacroDaemon`）；
   * 维护内部状态机：`IDLE` -> `RECORDING` -> `READY` -> `PLAYING`；
   * 绑定 `F2` / `F3` / `F9` 钩子处理与蜂鸣反馈；
   * 自动管理 `workspace/macros/_quick_loop.json`。
2. **`src/uiu/pattern_detector.py`（~100 行，纯标准库）**：
   * 动作序列周期检测与去噪，提取最小循环单元。
3. **`src/uiu/macros.py` 与 `src/uiu/commands.py` 联动**：
   * 注册 `quick_macro_start` / `quick_macro_stop` 工具供 agent 意图触发；
   * CLI 支持 `uiu quick` / `uiu macro quick` 一键前台启动。
